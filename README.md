# Dynamic Table Component with Virtual Scroll

A reusable, high-performance JavaScript table component that supports:

- Virtual scrolling (only visible rows in DOM)
- Sorting by columns
- Filtering by a selected field
- Reset functionality
- Clean style using plain CSS

## 🔧 How to Run

You must serve this using a local server to use ES modules.

### Option 1: Live Server (VS Code)
1. Install the Live Server extension.
2. Right-click `index.html` → “Open with Live Server”.

### Option 2: Using [`npx serve`](https://www.npmjs.com/package/serve).
Serving!
- Local: http://localhost:3000
